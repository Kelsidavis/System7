> ⚠️ **إثبات مفهوم** - هذا تطبيق تجريبي تعليمي لنظام Apple Macintosh System 7. هذا ليس منتجًا مكتملاً ولا ينبغي اعتباره برنامجًا جاهزًا للاستخدام الإنتاجي.

إعادة تطبيق مفتوحة المصدر لنظام Apple Macintosh System 7 للعتاد الحديث من نوع x86، قابلة للإقلاع عبر GRUB2/Multiboot2. يهدف هذا المشروع إلى إعادة إنشاء تجربة Mac OS الكلاسيكية مع توثيق بنية System 7 من خلال تحليل الهندسة العكسية.

## 🎯 حالة المشروع

**الحالة الراهنة**: تطوير نشط مع إنجاز حوالي 94% من الوظائف الأساسية

### آخر التحديثات (نوفمبر 2025)

#### تحسينات مدير الصوت ✅ مكتمل
- **تحويل MIDI محسّن**: دالة مساعدة مشتركة `SndMidiNoteToFreq()` مع جدول بحث من 37 مدخلاً (C3-B5) ورجوع مبني على الأوكتافات لنطاق MIDI الكامل (0-127)
- **دعم التشغيل غير المتزامن**: بنية تحتية كاملة لردود الاتصال لكل من تشغيل الملفات (`FilePlayCompletionUPP`) وتنفيذ الأوامر (`SndCallBackProcPtr`)
- **توجيه الصوت عبر القنوات**: نظام أولويات متعدد المستويات مع تحكم بالكتم والتفعيل
  - 4 مستويات أولوية للقنوات (0-3) لتوجيه إخراج العتاد
  - تحكم مستقل بالكتم والتفعيل لكل قناة
  - `SndGetActiveChannel()` تُرجع القناة النشطة ذات الأولوية الأعلى
  - تهيئة القنوات بشكل سليم مع علامة التفعيل افتراضيًا
- **تطبيق بجودة إنتاجية**: جميع الأكواد تُترجم بنجاح، لم يُكتشف أي انتهاكات في malloc/free
- **الإيداعات**: 07542c5 (تحسين MIDI)، 1854fe6 (ردود الاتصال غير المتزامنة)، a3433c6 (توجيه القنوات)

#### إنجازات الجلسات السابقة
- ✅ **مرحلة الميزات المتقدمة**: حلقة معالجة أوامر مدير الصوت، تسلسل أنماط التشغيل المتعدد، ميزات MIDI/التوليف الموسعة
- ✅ **نظام تغيير حجم النوافذ**: تغيير حجم تفاعلي مع معالجة سليمة لإطار النافذة ومربع التكبير وتنظيف سطح المكتب
- ✅ **ترجمة لوحة مفاتيح PS/2**: تعيين كامل لرموز المسح من المجموعة 1 إلى رموز مفاتيح Toolbox
- ✅ **طبقة تجريد العتاد متعددة المنصات**: دعم x86 وARM وPowerPC مع تجريد نظيف

## 📊 نسبة اكتمال المشروع

**الوظائف الأساسية الإجمالية**: حوالي 94% مكتملة (تقديرياً)

### ما يعمل بالكامل ✅

- **طبقة تجريد العتاد (HAL)**: تجريد منصات كامل لـ x86/ARM/PowerPC
- **نظام الإقلاع**: يقلع بنجاح عبر GRUB2/Multiboot2 على x86
- **التسجيل التسلسلي**: تسجيل قائم على الوحدات مع تصفية وقت التشغيل (Error/Warn/Info/Debug/Trace)
- **أساس الرسوميات**: مخزن إطارات VESA ‏(800x600x32) مع بدائيات QuickDraw بما في ذلك وضع XOR
- **عرض سطح المكتب**: شريط قوائم System 7 مع شعار Apple بألوان قوس قزح، والأيقونات، وأنماط سطح المكتب
- **الطباعة النصية**: خط Chicago النقطي بعرض مطابق للبكسل مع تباعد حروف سليم، وأحرف Mac Roman الموسعة (0x80-0xFF) للأحرف الأوروبية المشكّلة
- **التدويل (i18n)**: توطين قائم على الموارد مع 38 لغة (الإنجليزية، الفرنسية، الألمانية، الإسبانية، الإيطالية، البرتغالية، الهولندية، الدنماركية، النرويجية، السويدية، الفنلندية، الآيسلندية، اليونانية، التركية، البولندية، التشيكية، السلوفاكية، السلوفينية، الكرواتية، المجرية، الرومانية، البلغارية، الألبانية، الإستونية، اللاتفية، الليتوانية، المقدونية، الجبل الأسود، الروسية، الأوكرانية، العربية، اليابانية، الصينية المبسطة، الصينية التقليدية، الكورية، الهندية، البنغالية، الأردية)، مدير اللغات المحلية مع اختيار اللغة عند الإقلاع، بنية تحتية لترميز CJK متعدد البايت
- **مدير الخطوط**: دعم أحجام متعددة (9-24pt)، توليف الأنماط، تحليل FOND/NFNT، تخزين مؤقت LRU
- **نظام الإدخال**: لوحة مفاتيح وفأرة PS/2 مع توجيه كامل للأحداث
- **مدير الأحداث**: تعدد مهام تعاوني عبر WaitNextEvent مع طابور أحداث موحد
- **مدير الذاكرة**: تخصيص قائم على المناطق مع تكامل مفسر 68K
- **مدير القوائم**: قوائم منسدلة كاملة مع تتبع الفأرة وSaveBits/RestoreBits
- **نظام الملفات**: HFS مع تطبيق B-tree، ونوافذ المجلدات مع تعداد VFS
- **مدير النوافذ**: السحب، تغيير الحجم (مع مربع التكبير)، الطبقات، التنشيط
- **مدير الوقت**: معايرة دقيقة لـ TSC، دقة بالميكروثانية، فحص الأجيال
- **مدير الموارد**: بحث ثنائي O(log n)، تخزين مؤقت LRU، تحقق شامل
- **مدير Gestalt**: معلومات نظام متعددة البنى مع كشف البنية
- **مدير TextEdit**: تحرير نصوص كامل مع تكامل الحافظة
- **مدير Scrap**: حافظة Mac OS الكلاسيكية مع دعم أنواع متعددة
- **تطبيق SimpleText**: محرر نصوص MDI كامل الميزات مع قص/نسخ/لصق
- **مدير القوائم (List Manager)**: عناصر تحكم قوائم متوافقة مع System 7.1 مع التنقل بلوحة المفاتيح
- **مدير عناصر التحكم**: عناصر تحكم قياسية وأشرطة تمرير مع تطبيق CDEF
- **مدير مربعات الحوار**: التنقل بلوحة المفاتيح، حلقات التركيز، اختصارات لوحة المفاتيح
- **محمّل المقاطع**: نظام تحميل مقاطع 68K محمول ومستقل عن بنية المعالج مع إعادة التوجيه
- **مفسر M68K**: إرسال تعليمات كامل مع 84 معالج أكواد عمليات، وجميع أوضاع العنونة الـ14، وإطار الاستثناءات/الاعتراضات
- **مدير الصوت**: معالجة الأوامر، تحويل MIDI، إدارة القنوات، ردود الاتصال
- **مدير الأجهزة**: إدارة DCE، تثبيت/إزالة برامج التشغيل، وعمليات الإدخال/الإخراج
- **شاشة البدء**: واجهة إقلاع كاملة مع تتبع التقدم، وإدارة المراحل، وشاشة الترحيب
- **مدير الألوان**: إدارة حالة الألوان مع تكامل QuickDraw

### مُطبّق جزئياً ⚠️

- **تكامل التطبيقات**: مفسر M68K ومحمّل المقاطع مكتملان؛ يلزم اختبار التكامل للتحقق من تنفيذ التطبيقات الحقيقية
- **إجراءات تعريف النوافذ (WDEF)**: البنية الأساسية جاهزة، إرسال جزئي
- **مدير الكلام**: إطار API وتمرير الصوت فقط؛ محرك توليف الكلام غير مُطبّق
- **معالجة الاستثناءات (RTE)**: العودة من الاستثناء مُطبّقة جزئياً (حالياً يتوقف بدلاً من استعادة السياق)

### لم يُطبّق بعد ❌

- **الطباعة**: لا يوجد نظام طباعة
- **الشبكات**: لا توجد وظائف AppleTalk أو شبكات
- **ملحقات المكتب**: الإطار فقط
- **الصوت المتقدم**: تشغيل العينات، المزج (قيود مكبر صوت الحاسوب)

### أنظمة فرعية غير مُترجمة 🔧

يوجد لها شفرة مصدرية لكنها غير مدمجة في النواة:
- **AppleEventManager** ‏(8 ملفات): الرسائل بين التطبيقات؛ مستبعد عمداً بسبب اعتماده على pthread غير المتوافق مع البيئة المستقلة
- **FontResources** ‏(ملف ترويسة فقط): تعريفات أنواع موارد الخطوط؛ دعم الخطوط الفعلي يوفره الملف المُترجم FontResourceLoader.c

## 🏗️ البنية

### المواصفات التقنية

- **البنية**: متعددة البنى عبر HAL ‏(x86، ARM، PowerPC جاهزة)
- **بروتوكول الإقلاع**: Multiboot2 ‏(x86)، محمّلات إقلاع خاصة بالمنصة
- **الرسوميات**: مخزن إطارات VESA، ‏800x600 @ 32-bit ألوان
- **تخطيط الذاكرة**: النواة تُحمّل عند العنوان الفيزيائي 1MB ‏(x86)
- **التوقيت**: مستقل عن البنية بدقة ميكروثانية (RDTSC/سجلات المؤقت)
- **الأداء**: خطأ مورد بارد <15µs، إصابة تخزين مؤقت <2µs، انحراف المؤقت <100ppm

### إحصائيات قاعدة الكود

- **أكثر من 225 ملف مصدري** بأكثر من ~57,500 سطر كود
- **أكثر من 145 ملف ترويسة** عبر أكثر من 28 نظاماً فرعياً
- **69 نوع مورد** مُستخرج من System 7.1
- **زمن الترجمة**: 3-5 ثوانٍ على عتاد حديث
- **حجم النواة**: ~4.16 ميغابايت
- **حجم ISO**: ~12.5 ميغابايت

## 🔨 البناء

### المتطلبات

- **GCC** مع دعم 32-bit ‏(`gcc-multilib` على أنظمة 64-bit)
- **GNU Make**
- **أدوات GRUB**: `grub-mkrescue` (من `grub2-common` أو `grub-pc-bin`)
- **QEMU** للاختبار (`qemu-system-i386`)
- **Python 3** لمعالجة الموارد
- **xxd** للتحويل الثنائي
- *(اختياري)* سلسلة أدوات **powerpc-linux-gnu** للبناء المتقاطع لـ PowerPC

### التثبيت على Ubuntu/Debian

```bash
sudo apt-get install build-essential gcc-multilib grub-pc-bin xorriso qemu-system-x86 python3 vim-common
```

### أوامر البناء

```bash
# بناء النواة (x86 افتراضياً)
make

# البناء لمنصة محددة
make PLATFORM=x86
make PLATFORM=arm        # يتطلب GCC للعتاد المعدني ARM
make PLATFORM=ppc        # تجريبي؛ يتطلب سلسلة أدوات PowerPC ELF

# إنشاء ملف ISO قابل للإقلاع
make iso

# البناء مع جميع اللغات
make LOCALE_FR=1 LOCALE_DE=1 LOCALE_ES=1 LOCALE_JA=1 LOCALE_ZH=1 LOCALE_KO=1 LOCALE_RU=1 LOCALE_UK=1 LOCALE_PL=1 LOCALE_CS=1 LOCALE_SQ=1 LOCALE_BG=1 LOCALE_HR=1 LOCALE_DA=1 LOCALE_NL=1 LOCALE_ET=1 LOCALE_FI=1 LOCALE_EL=1 LOCALE_HU=1 LOCALE_IS=1 LOCALE_IT=1 LOCALE_LV=1 LOCALE_LT=1 LOCALE_MK=1 LOCALE_ME=1 LOCALE_NO=1 LOCALE_PT=1 LOCALE_RO=1 LOCALE_SK=1 LOCALE_SL=1 LOCALE_SV=1 LOCALE_TR=1 LOCALE_HI=1 LOCALE_TW=1 LOCALE_AR=1 LOCALE_BN=1 LOCALE_UR=1

# البناء مع لغة إضافية واحدة
make LOCALE_FR=1

# البناء والتشغيل في QEMU
make run

# تنظيف الملفات المُنتجة
make clean

# عرض إحصائيات البناء
make info
```

## 🚀 التشغيل

### البدء السريع (QEMU)

```bash
# تشغيل قياسي مع التسجيل التسلسلي
make run

# يدوياً مع خيارات
qemu-system-i386 -cdrom system71.iso -serial file:/tmp/serial.log -display sdl -vga std -m 256M
```

### خيارات QEMU

```bash
# مع إخراج تسلسلي على وحدة التحكم
qemu-system-i386 -cdrom system71.iso -serial stdio -display sdl -m 256M

# بدون واجهة رسومية
qemu-system-i386 -cdrom system71.iso -serial stdio -display none -m 256M

# مع تنقيح GDB
make debug
# في طرفية أخرى: gdb kernel.elf -ex "target remote :1234"
```

## 🐛 المشكلات المعروفة

1. **عيوب سحب الأيقونات**: عيوب بصرية طفيفة أثناء سحب أيقونات سطح المكتب
2. **تنفيذ M68K مُعطّل**: محمّل المقاطع مكتمل، حلقة التنفيذ غير مُطبّقة

5. **لا ضمانات للاستقرار**: الأعطال والسلوك غير المتوقع شائعان
