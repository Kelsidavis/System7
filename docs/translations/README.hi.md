> ⚠️ **प्रूफ ऑफ कॉन्सेप्ट** - यह Apple के Macintosh System 7 का एक प्रयोगात्मक, शैक्षिक पुनर्निर्माण है। यह एक तैयार उत्पाद नहीं है और इसे उत्पादन-योग्य सॉफ़्टवेयर नहीं माना जाना चाहिए।

आधुनिक x86 हार्डवेयर के लिए Apple Macintosh System 7 का एक ओपन-सोर्स पुनर्निर्माण, जो GRUB2/Multiboot2 के माध्यम से बूट होता है। इस परियोजना का उद्देश्य रिवर्स इंजीनियरिंग विश्लेषण के माध्यम से System 7 की वास्तुकला को प्रलेखित करते हुए क्लासिक Mac OS अनुभव को पुनर्निर्मित करना है।

## 🎯 परियोजना की स्थिति

**वर्तमान स्थिति**: ~94% मुख्य कार्यक्षमता पूर्ण के साथ सक्रिय विकास

### नवीनतम अपडेट (नवम्बर 2025)

#### Sound Manager संवर्द्धन ✅ पूर्ण
- **अनुकूलित MIDI रूपांतरण**: 37-प्रविष्टि लुकअप तालिका (C3-B5) और पूर्ण MIDI रेंज (0-127) के लिए ऑक्टेव-आधारित फ़ॉलबैक के साथ साझा `SndMidiNoteToFreq()` हेल्पर
- **एसिंक प्लेबैक सपोर्ट**: फ़ाइल प्लेबैक (`FilePlayCompletionUPP`) और कमांड निष्पादन (`SndCallBackProcPtr`) दोनों के लिए पूर्ण कॉलबैक अवसंरचना
- **चैनल-आधारित ऑडियो रूटिंग**: म्यूट और इनेबल नियंत्रणों के साथ बहु-स्तरीय प्राथमिकता प्रणाली
  - हार्डवेयर आउटपुट रूटिंग के लिए 4-स्तरीय प्राथमिकता चैनल (0-3)
  - प्रत्येक चैनल के लिए स्वतंत्र म्यूट और इनेबल नियंत्रण
  - `SndGetActiveChannel()` सर्वोच्च-प्राथमिकता वाला सक्रिय चैनल लौटाता है
  - डिफ़ॉल्ट रूप से इनेबल्ड फ़्लैग के साथ उचित चैनल आरंभीकरण
- **उत्पादन-गुणवत्ता कार्यान्वयन**: सभी कोड बिना त्रुटि के संकलित, कोई malloc/free उल्लंघन नहीं पाया गया
- **कमिट**: 07542c5 (MIDI अनुकूलन), 1854fe6 (एसिंक कॉलबैक), a3433c6 (चैनल रूटिंग)

#### पिछले सत्र की उपलब्धियाँ
- ✅ **उन्नत सुविधाएँ चरण**: Sound Manager कमांड प्रोसेसिंग लूप, मल्टी-रन स्टाइल सीरियलाइज़ेशन, विस्तारित MIDI/सिंथेसिस सुविधाएँ
- ✅ **विंडो रिसाइज़ प्रणाली**: उचित क्रोम हैंडलिंग, ग्रो बॉक्स और डेस्कटॉप क्लीनअप के साथ इंटरैक्टिव रिसाइज़िंग
- ✅ **PS/2 कीबोर्ड अनुवाद**: पूर्ण सेट 1 स्कैनकोड से Toolbox कुंजी कोड मैपिंग
- ✅ **मल्टी-प्लेटफ़ॉर्म HAL**: स्वच्छ अमूर्तता के साथ x86, ARM और PowerPC सपोर्ट

## 📊 परियोजना पूर्णता

**समग्र मुख्य कार्यक्षमता**: ~94% पूर्ण (अनुमानित)

### पूर्ण रूप से काम करता है ✅

- **Hardware Abstraction Layer (HAL)**: x86/ARM/PowerPC के लिए पूर्ण प्लेटफ़ॉर्म अमूर्तता
- **बूट सिस्टम**: x86 पर GRUB2/Multiboot2 के माध्यम से सफलतापूर्वक बूट होता है
- **सीरियल लॉगिंग**: रनटाइम फ़िल्टरिंग (Error/Warn/Info/Debug/Trace) के साथ मॉड्यूल-आधारित लॉगिंग
- **ग्राफ़िक्स आधार**: XOR मोड सहित QuickDraw प्रिमिटिव्स के साथ VESA फ़्रेमबफ़र (800x600x32)
- **डेस्कटॉप रेंडरिंग**: रेनबो Apple लोगो, आइकन और डेस्कटॉप पैटर्न के साथ System 7 मेन्यू बार
- **टाइपोग्राफ़ी**: पिक्सेल-परफ़ेक्ट रेंडरिंग और उचित कर्निंग के साथ Chicago बिटमैप फ़ॉन्ट, यूरोपीय उच्चारण चिह्न वाले अक्षरों के लिए विस्तारित Mac Roman (0x80-0xFF)
- **अंतर्राष्ट्रीयकरण (i18n)**: 38 भाषाओं (अंग्रेज़ी, फ़्रेंच, जर्मन, स्पेनिश, इतालवी, पुर्तगाली, डच, डेनिश, नॉर्वेजियन, स्वीडिश, फ़िनिश, आइसलैंडिक, ग्रीक, तुर्की, पोलिश, चेक, स्लोवाक, स्लोवेनियाई, क्रोएशियाई, हंगेरियन, रोमानियाई, बल्गेरियाई, अल्बानियाई, एस्टोनियाई, लातवियाई, लिथुआनियाई, मैसेडोनियाई, मोंटेनेग्रिन, रूसी, यूक्रेनियाई, अरबी, जापानी, सरलीकृत चीनी, पारंपरिक चीनी, कोरियाई, हिन्दी, बांग्ला, उर्दू) के साथ संसाधन-आधारित स्थानीयकरण, बूट-टाइम भाषा चयन के साथ Locale Manager, CJK मल्टी-बाइट एन्कोडिंग अवसंरचना
- **Font Manager**: बहु-आकार सपोर्ट (9-24pt), स्टाइल सिंथेसिस, FOND/NFNT पार्सिंग, LRU कैशिंग
- **इनपुट सिस्टम**: पूर्ण इवेंट फ़ॉरवर्डिंग के साथ PS/2 कीबोर्ड और माउस
- **Event Manager**: एकीकृत इवेंट कतार के साथ WaitNextEvent द्वारा सहकारी मल्टीटास्किंग
- **Memory Manager**: 68K इंटरप्रेटर एकीकरण के साथ ज़ोन-आधारित आवंटन
- **Menu Manager**: माउस ट्रैकिंग और SaveBits/RestoreBits के साथ पूर्ण ड्रॉपडाउन मेन्यू
- **File System**: B-tree कार्यान्वयन के साथ HFS, VFS गणना के साथ फ़ोल्डर विंडो
- **Window Manager**: ड्रैगिंग, रिसाइज़िंग (ग्रो बॉक्स के साथ), लेयरिंग, एक्टिवेशन
- **Time Manager**: सटीक TSC कैलिब्रेशन, माइक्रोसेकंड परिशुद्धता, जेनरेशन चेकिंग
- **Resource Manager**: O(log n) बाइनरी सर्च, LRU कैश, व्यापक सत्यापन
- **Gestalt Manager**: आर्किटेक्चर डिटेक्शन के साथ बहु-आर्किटेक्चर सिस्टम जानकारी
- **TextEdit Manager**: क्लिपबोर्ड एकीकरण के साथ पूर्ण टेक्स्ट एडिटिंग
- **Scrap Manager**: एकाधिक फ़्लेवर सपोर्ट के साथ क्लासिक Mac OS क्लिपबोर्ड
- **SimpleText एप्लिकेशन**: कट/कॉपी/पेस्ट के साथ पूर्ण-विशेषता MDI टेक्स्ट एडिटर
- **List Manager**: कीबोर्ड नेविगेशन के साथ System 7.1-संगत लिस्ट कंट्रोल
- **Control Manager**: CDEF कार्यान्वयन के साथ मानक और स्क्रॉलबार कंट्रोल
- **Dialog Manager**: कीबोर्ड नेविगेशन, फ़ोकस रिंग, कीबोर्ड शॉर्टकट
- **Segment Loader**: रिलोकेशन के साथ पोर्टेबल ISA-अज्ञेय 68K सेगमेंट लोडिंग सिस्टम
- **M68K Interpreter**: 84 ऑपकोड हैंडलर, सभी 14 एड्रेसिंग मोड, एक्सेप्शन/ट्रैप फ़्रेमवर्क के साथ पूर्ण निर्देश डिस्पैच
- **Sound Manager**: कमांड प्रोसेसिंग, MIDI रूपांतरण, चैनल प्रबंधन, कॉलबैक
- **Device Manager**: DCE प्रबंधन, ड्राइवर इंस्टॉलेशन/रिमूवल, और I/O ऑपरेशन
- **Startup Screen**: प्रगति ट्रैकिंग, चरण प्रबंधन और स्प्लैश स्क्रीन के साथ पूर्ण बूट UI
- **Color Manager**: QuickDraw एकीकरण के साथ रंग स्थिति प्रबंधन

### आंशिक रूप से कार्यान्वित ⚠️

- **एप्लिकेशन एकीकरण**: M68K इंटरप्रेटर और सेगमेंट लोडर पूर्ण; वास्तविक एप्लिकेशन निष्पादन सत्यापन के लिए एकीकरण परीक्षण आवश्यक
- **Window Definition Procedures (WDEF)**: मुख्य संरचना यथास्थान, आंशिक डिस्पैच
- **Speech Manager**: केवल API फ़्रेमवर्क और ऑडियो पासथ्रू; स्पीच सिंथेसिस इंजन कार्यान्वित नहीं
- **Exception Handling (RTE)**: एक्सेप्शन से वापसी आंशिक रूप से कार्यान्वित (वर्तमान में संदर्भ पुनर्स्थापित करने के बजाय रुक जाता है)

### अभी तक कार्यान्वित नहीं ❌

- **प्रिंटिंग**: कोई प्रिंट सिस्टम नहीं
- **नेटवर्किंग**: कोई AppleTalk या नेटवर्क कार्यक्षमता नहीं
- **Desk Accessories**: केवल फ़्रेमवर्क
- **उन्नत ऑडियो**: सैंपल प्लेबैक, मिक्सिंग (PC स्पीकर सीमा)

### संकलित नहीं किए गए उपप्रणालियाँ 🔧

निम्नलिखित में सोर्स कोड है लेकिन कर्नेल में एकीकृत नहीं हैं:
- **AppleEventManager** (8 फ़ाइलें): अंतर-अनुप्रयोग संदेशन; फ़्रीस्टैंडिंग वातावरण के साथ असंगत pthread निर्भरताओं के कारण जानबूझकर बाहर रखा गया
- **FontResources** (केवल हेडर): फ़ॉन्ट संसाधन प्रकार परिभाषाएँ; वास्तविक फ़ॉन्ट सपोर्ट संकलित FontResourceLoader.c द्वारा प्रदान किया जाता है

## 🏗️ वास्तुकला

### तकनीकी विनिर्देश

- **आर्किटेक्चर**: HAL के माध्यम से बहु-आर्किटेक्चर (x86, ARM, PowerPC तैयार)
- **बूट प्रोटोकॉल**: Multiboot2 (x86), प्लेटफ़ॉर्म-विशिष्ट बूटलोडर
- **ग्राफ़िक्स**: VESA फ़्रेमबफ़र, 800x600 @ 32-बिट रंग
- **मेमोरी लेआउट**: कर्नेल 1MB भौतिक पते पर लोड होता है (x86)
- **टाइमिंग**: माइक्रोसेकंड परिशुद्धता के साथ आर्किटेक्चर-अज्ञेय (RDTSC/टाइमर रजिस्टर)
- **प्रदर्शन**: कोल्ड रिसोर्स मिस <15µs, कैश हिट <2µs, टाइमर ड्रिफ़्ट <100ppm

### कोडबेस आँकड़े

- **225+ सोर्स फ़ाइलें** ~57,500+ कोड की पंक्तियों के साथ
- **145+ हेडर फ़ाइलें** 28+ उपप्रणालियों में
- **69 संसाधन प्रकार** System 7.1 से निकाले गए
- **संकलन समय**: आधुनिक हार्डवेयर पर 3-5 सेकंड
- **कर्नेल आकार**: ~4.16 MB
- **ISO आकार**: ~12.5 MB

## 🔨 निर्माण

### आवश्यकताएँ

- **GCC** 32-बिट सपोर्ट के साथ (64-बिट पर `gcc-multilib`)
- **GNU Make**
- **GRUB उपकरण**: `grub-mkrescue` (`grub2-common` या `grub-pc-bin` से)
- **QEMU** परीक्षण के लिए (`qemu-system-i386`)
- **Python 3** संसाधन प्रसंस्करण के लिए
- **xxd** बाइनरी रूपांतरण के लिए
- *(वैकल्पिक)* PowerPC बिल्ड के लिए **powerpc-linux-gnu** क्रॉस टूलचेन

### Ubuntu/Debian इंस्टॉलेशन

```bash
sudo apt-get install build-essential gcc-multilib grub-pc-bin xorriso qemu-system-x86 python3 vim-common
```

### बिल्ड कमांड

```bash
# कर्नेल बिल्ड करें (डिफ़ॉल्ट रूप से x86)
make

# विशिष्ट प्लेटफ़ॉर्म के लिए बिल्ड करें
make PLATFORM=x86
make PLATFORM=arm        # ARM बेयर-मेटल GCC आवश्यक
make PLATFORM=ppc        # प्रयोगात्मक; PowerPC ELF टूलचेन आवश्यक

# बूट योग्य ISO बनाएँ
make iso

# सभी भाषाओं के साथ बिल्ड करें
make LOCALE_FR=1 LOCALE_DE=1 LOCALE_ES=1 LOCALE_JA=1 LOCALE_ZH=1 LOCALE_KO=1 LOCALE_RU=1 LOCALE_UK=1 LOCALE_PL=1 LOCALE_CS=1 LOCALE_SQ=1 LOCALE_BG=1 LOCALE_HR=1 LOCALE_DA=1 LOCALE_NL=1 LOCALE_ET=1 LOCALE_FI=1 LOCALE_EL=1 LOCALE_HU=1 LOCALE_IS=1 LOCALE_IT=1 LOCALE_LV=1 LOCALE_LT=1 LOCALE_MK=1 LOCALE_ME=1 LOCALE_NO=1 LOCALE_PT=1 LOCALE_RO=1 LOCALE_SK=1 LOCALE_SL=1 LOCALE_SV=1 LOCALE_TR=1 LOCALE_HI=1 LOCALE_TW=1 LOCALE_AR=1 LOCALE_BN=1 LOCALE_UR=1

# एक अतिरिक्त भाषा के साथ बिल्ड करें
make LOCALE_FR=1

# बिल्ड करें और QEMU में चलाएँ
make run

# आर्टिफ़ैक्ट साफ़ करें
make clean

# बिल्ड आँकड़े प्रदर्शित करें
make info
```

## 🚀 चलाना

### त्वरित प्रारंभ (QEMU)

```bash
# सीरियल लॉगिंग के साथ मानक रन
make run

# विकल्पों के साथ मैन्युअल रूप से
qemu-system-i386 -cdrom system71.iso -serial file:/tmp/serial.log -display sdl -vga std -m 256M
```

### QEMU विकल्प

```bash
# कंसोल सीरियल आउटपुट के साथ
qemu-system-i386 -cdrom system71.iso -serial stdio -display sdl -m 256M

# हेडलेस (कोई ग्राफ़िक्स डिस्प्ले नहीं)
qemu-system-i386 -cdrom system71.iso -serial stdio -display none -m 256M

# GDB डिबगिंग के साथ
make debug
# दूसरे टर्मिनल में: gdb kernel.elf -ex "target remote :1234"
```

### परियोजना दर्शन

**पुरातात्विक दृष्टिकोण** साक्ष्य-आधारित कार्यान्वयन के साथ:
1. Inside Macintosh प्रलेखन और MPW Universal Interfaces द्वारा समर्थित
2. सभी प्रमुख निर्णय सहायक साक्ष्य को संदर्भित करने वाले Finding IDs के साथ टैग किए गए
3. लक्ष्य: मूल System 7 के साथ व्यवहारिक समानता, आधुनिकीकरण नहीं
4. क्लीन-रूम कार्यान्वयन (कोई मूल Apple सोर्स कोड नहीं)

## 🐛 ज्ञात समस्याएँ

1. **आइकन ड्रैग आर्टिफ़ैक्ट**: डेस्कटॉप आइकन ड्रैग करते समय मामूली दृश्य आर्टिफ़ैक्ट
2. **M68K निष्पादन स्टब्ड**: सेगमेंट लोडर पूर्ण, निष्पादन लूप कार्यान्वित नहीं
3. **कोई TrueType सपोर्ट नहीं**: केवल बिटमैप फ़ॉन्ट (Chicago)
4. **HFS केवल-पठन**: वर्चुअल फ़ाइल सिस्टम, कोई वास्तविक डिस्क राइट-बैक नहीं
5. **कोई स्थिरता गारंटी नहीं**: क्रैश और अप्रत्याशित व्यवहार आम हैं

## 🤝 योगदान

यह मुख्य रूप से एक शिक्षण/अनुसंधान परियोजना है:

1. **बग रिपोर्ट**: विस्तृत पुनरुत्पादन चरणों के साथ समस्याएँ दर्ज करें
2. **परीक्षण**: विभिन्न हार्डवेयर/एमुलेटर पर परिणाम रिपोर्ट करें
3. **प्रलेखन**: मौजूदा दस्तावेज़ों में सुधार करें या नई गाइड जोड़ें
