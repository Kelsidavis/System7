> ⚠️ **ДОКАЗ НА КОНЦЕПТ** - Ова е експериментална, образовна реимплементација на Apple Macintosh System 7. Ова НЕ е готов производ и не треба да се смета за софтвер подготвен за продукција.

Реимплементација со отворен код на Apple Macintosh System 7 за модерен x86 хардвер, со подигнување преку GRUB2/Multiboot2. Овој проект има за цел да го рекреира класичното Mac OS искуство додека ја документира архитектурата на System 7 преку анализа на обратен инженеринг.

## 🎯 Статус на проектот

**Тековна состојба**: Активен развој со ~94% завршена основна функционалност

### Последни ажурирања (ноември 2025)

#### Подобрувања на Sound Manager ✅ ЗАВРШЕНО
- **Оптимизирана MIDI конверзија**: Споделена помошна функција `SndMidiNoteToFreq()` со табела за пребарување од 37 записи (C3-B5) и резервен механизам базиран на октави за целосен MIDI опсег (0-127)
- **Поддршка за асинхрона репродукција**: Целосна инфраструктура за повратни повици и за репродукција на датотеки (`FilePlayCompletionUPP`) и за извршување команди (`SndCallBackProcPtr`)
- **Аудио рутирање базирано на канали**: Систем со повеќе нивоа на приоритет со контроли за исклучување и овозможување
  - 4-нивоен приоритетен канал (0-3) за рутирање на хардверски излез
  - Независни контроли за исклучување и овозможување по канал
  - `SndGetActiveChannel()` го враќа каналот со највисок приоритет
  - Правилна иницијализација на каналот со стандардно овозможено знаменце
- **Имплементација со продукциски квалитет**: Целиот код се компајлира чисто, без откриени прекршувања на malloc/free
- **Комити**: 07542c5 (MIDI оптимизација), 1854fe6 (асинхрони повратни повици), a3433c6 (рутирање на канали)

#### Претходни достигнувања
- ✅ **Фаза на напредни функции**: Циклус за обработка на команди на Sound Manager, серијализација на стилови за повеќе извршувања, проширени MIDI/синтеза функции
- ✅ **Систем за промена на големина на прозорец**: Интерактивна промена на големина со правилно ракување со рамката, кутија за зголемување и чистење на работната површина
- ✅ **PS/2 превод на тастатура**: Целосно мапирање на скенкодови од сет 1 кон кодови на копчиња на Toolbox
- ✅ **Повеќеплатформски HAL**: Поддршка за x86, ARM и PowerPC со чиста апстракција

## 📊 Комплетност на проектот

**Вкупна основна функционалност**: ~94% завршена (проценка)

### Што работи целосно ✅

- **Слој за апстракција на хардвер (HAL)**: Целосна платформска апстракција за x86/ARM/PowerPC
- **Систем за подигнување**: Успешно подигнување преку GRUB2/Multiboot2 на x86
- **Серијално логирање**: Логирање базирано на модули со филтрирање при извршување (Error/Warn/Info/Debug/Trace)
- **Графичка основа**: VESA фрејмбафер (800x600x32) со QuickDraw примитиви вклучувајќи XOR режим
- **Рендерирање на работна површина**: Лента со менија на System 7 со виножитно Apple лого, икони и шаблони за работна површина
- **Типографија**: Chicago битмап фонт со пиксел-совршено рендерирање и правилен кернинг, проширен Mac Roman (0x80-0xFF) за европски акцентирани букви
- **Интернационализација (i18n)**: Локализација базирана на ресурси со 38 јазици (англиски, француски, германски, шпански, италијански, португалски, холандски, дански, норвешки, шведски, фински, исландски, грчки, турски, полски, чешки, словачки, словенечки, хрватски, унгарски, романски, бугарски, албански, естонски, латвиски, литвански, македонски, црногорски, руски, украински, арапски, јапонски, поедноставен кинески, традиционален кинески, корејски, хинди, бенгалски, урду), Locale Manager со избор на јазик при подигнување, CJK инфраструктура за повеќебајтно кодирање
- **Font Manager**: Поддршка за повеќе големини (9-24pt), синтеза на стилови, парсирање на FOND/NFNT, LRU кеширање
- **Систем за внес**: PS/2 тастатура и глушец со целосно проследување на настани
- **Event Manager**: Кооперативно мултитаскирање преку WaitNextEvent со унифициран ред на настани
- **Memory Manager**: Алокација базирана на зони со интеграција на 68K интерпретер
- **Menu Manager**: Целосни паѓачки менија со следење на глушец и SaveBits/RestoreBits
- **Датотечен систем**: HFS со имплементација на B-tree, прозорци за папки со VFS набројување
- **Window Manager**: Влечење, промена на големина (со кутија за зголемување), слоеви, активација
- **Time Manager**: Точна TSC калибрација, микросекундна прецизност, проверка на генерација
- **Resource Manager**: O(log n) бинарно пребарување, LRU кеш, сеопфатна валидација
- **Gestalt Manager**: Системски информации за повеќе архитектури со детекција на архитектура
- **TextEdit Manager**: Целосно уредување на текст со интеграција на клипборд
- **Scrap Manager**: Класичен Mac OS клипборд со поддршка за повеќе формати
- **Апликација SimpleText**: Целосен MDI уредувач на текст со исечи/копирај/залепи
- **List Manager**: Контроли за листи компатибилни со System 7.1 со навигација преку тастатура
- **Control Manager**: Стандардни контроли и ленти за лизгање со имплементација на CDEF
- **Dialog Manager**: Навигација преку тастатура, рамки за фокус, кратенки преку тастатура
- **Segment Loader**: Преносив систем за вчитување на 68K сегменти независен од ISA со релокација
- **M68K интерпретер**: Целосно распределување на инструкции со 84 ракувачи за опкодови, сите 14 режими на адресирање, рамка за исклучоци/замки
- **Sound Manager**: Обработка на команди, MIDI конверзија, управување со канали, повратни повици
- **Device Manager**: Управување со DCE, инсталација/отстранување на драјвери и I/O операции
- **Екран за стартување**: Целосен UI за подигнување со следење на напредокот, управување со фази и приказ на почетен екран
- **Color Manager**: Управување со состојба на бои со интеграција со QuickDraw

### Делумно имплементирано ⚠️

- **Интеграција на апликации**: M68K интерпретерот и сегментниот вчитувач се завршени; потребно е интеграциско тестирање за да се потврди дека реалните апликации се извршуваат
- **Процедури за дефиниција на прозорец (WDEF)**: Основната структура е поставена, делумно распределување
- **Speech Manager**: Само рамка за API и аудио проследување; моторот за синтеза на говор не е имплементиран
- **Ракување со исклучоци (RTE)**: Враќањето од исклучок е делумно имплементирано (моментално запира наместо да го обнови контекстот)

### Сеуште не е имплементирано ❌

- **Печатење**: Нема систем за печатење
- **Мрежа**: Нема AppleTalk или мрежна функционалност
- **Помошни програми за работна површина**: Само рамка
- **Напреден аудио**: Репродукција на семпли, миксање (ограничување на PC звучникот)

### Потсистеми кои не се компајлирани 🔧

Следниве имаат изворен код, но не се интегрирани во кернелот:
- **AppleEventManager** (8 датотеки): Меѓуапликациски пораки; намерно исклучен поради pthread зависности некомпатибилни со самостојна средина
- **FontResources** (само заглавје): Дефиниции на типови на фонт ресурси; вистинската поддршка за фонтови е обезбедена од компајлираниот FontResourceLoader.c

## 🏗️ Архитектура

### Технички спецификации

- **Архитектура**: Повеќе архитектури преку HAL (x86, ARM, PowerPC подготвени)
- **Протокол за подигнување**: Multiboot2 (x86), платформско-специфични подигнувачи
- **Графика**: VESA фрејмбафер, 800x600 @ 32-битна боја
- **Распоред на меморија**: Кернелот се вчитува на 1MB физичка адреса (x86)
- **Тајминг**: Архитектурски агностичен со микросекундна прецизност (RDTSC/тајмер регистри)
- **Перформанси**: Промашување на ладен ресурс <15µs, погодок на кеш <2µs, дрифт на тајмер <100ppm

### Статистика на кодната база

- **225+ изворни датотеки** со ~57.500+ линии код
- **145+ заглавни датотеки** низ 28+ потсистеми
- **69 типови на ресурси** извлечени од System 7.1
- **Време на компајлирање**: 3-5 секунди на модерен хардвер
- **Големина на кернел**: ~4,16 MB
- **Големина на ISO**: ~12,5 MB

## 🔨 Компајлирање

### Барања

- **GCC** со поддршка за 32-бит (`gcc-multilib` на 64-битни системи)
- **GNU Make**
- **GRUB алатки**: `grub-mkrescue` (од `grub2-common` или `grub-pc-bin`)
- **QEMU** за тестирање (`qemu-system-i386`)
- **Python 3** за обработка на ресурси
- **xxd** за бинарна конверзија
- *(Опционално)* **powerpc-linux-gnu** вкрстена алатка за PowerPC компајлирања

### Инсталација на Ubuntu/Debian

```bash
sudo apt-get install build-essential gcc-multilib grub-pc-bin xorriso qemu-system-x86 python3 vim-common
```

### Команди за компајлирање

```bash
# Build kernel (x86 by default)
make

# Build for specific platform
make PLATFORM=x86
make PLATFORM=arm        # requires ARM bare-metal GCC
make PLATFORM=ppc        # experimental; requires PowerPC ELF toolchain

# Create bootable ISO
make iso

# Build with all languages
make LOCALE_FR=1 LOCALE_DE=1 LOCALE_ES=1 LOCALE_JA=1 LOCALE_ZH=1 LOCALE_KO=1 LOCALE_RU=1 LOCALE_UK=1 LOCALE_PL=1 LOCALE_CS=1 LOCALE_SQ=1 LOCALE_BG=1 LOCALE_HR=1 LOCALE_DA=1 LOCALE_NL=1 LOCALE_ET=1 LOCALE_FI=1 LOCALE_EL=1 LOCALE_HU=1 LOCALE_IS=1 LOCALE_IT=1 LOCALE_LV=1 LOCALE_LT=1 LOCALE_MK=1 LOCALE_ME=1 LOCALE_NO=1 LOCALE_PT=1 LOCALE_RO=1 LOCALE_SK=1 LOCALE_SL=1 LOCALE_SV=1 LOCALE_TR=1 LOCALE_HI=1 LOCALE_TW=1 LOCALE_AR=1 LOCALE_BN=1 LOCALE_UR=1

# Build with a single additional language
make LOCALE_FR=1

# Build and run in QEMU
make run

# Clean artifacts
make clean

# Display build statistics
make info
```

## 🐛 Познати проблеми

1. **Артефакти при влечење на икони**: Мали визуелни артефакти при влечење на иконите на работната површина
2. **M68K извршувањето е стабирано**: Сегментниот вчитувач е завршен, циклусот за извршување не е имплементиран
3. **Нема поддршка за TrueType**: Само битмап фонтови (Chicago)
4. **HFS само за читање**: Виртуелен датотечен систем, нема враќање на запис на диск
5. **Нема гаранции за стабилност**: Падови и неочекувано однесување се чести
