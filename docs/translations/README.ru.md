> ⚠️ **ПРОТОТИП** — Это экспериментальная образовательная реализация Apple Macintosh System 7. Это НЕ готовый продукт и не должно рассматриваться как программное обеспечение, готовое к промышленному использованию.

Реализация с открытым исходным кодом Apple Macintosh System 7 для современного оборудования x86, загружаемая через GRUB2/Multiboot2. Цель проекта — воссоздать классический интерфейс Mac OS, документируя архитектуру System 7 посредством обратной разработки.

## 🎯 Статус проекта

**Текущее состояние**: Активная разработка, ~94% основной функциональности реализовано

### Последние обновления (ноябрь 2025)

#### Улучшения Sound Manager ✅ ЗАВЕРШЕНО
- **Оптимизированная конвертация MIDI**: Общая вспомогательная функция `SndMidiNoteToFreq()` с таблицей поиска на 37 записей (C3-B5) и октавным запасным механизмом для полного диапазона MIDI (0-127)
- **Поддержка асинхронного воспроизведения**: Полная инфраструктура обратных вызовов для воспроизведения файлов (`FilePlayCompletionUPP`) и выполнения команд (`SndCallBackProcPtr`)
- **Маршрутизация звука на основе каналов**: Многоуровневая система приоритетов с управлением отключением и включением звука
  - 4-уровневые каналы приоритетов (0-3) для маршрутизации аппаратного вывода
  - Независимое управление отключением и включением для каждого канала
  - `SndGetActiveChannel()` возвращает активный канал с наивысшим приоритетом
  - Корректная инициализация каналов с флагом включения по умолчанию
- **Реализация промышленного качества**: Весь код компилируется без предупреждений, нарушений malloc/free не обнаружено
- **Коммиты**: 07542c5 (оптимизация MIDI), 1854fe6 (асинхронные обратные вызовы), a3433c6 (маршрутизация каналов)

#### Достижения предыдущих сессий
- ✅ **Фаза расширенных возможностей**: Цикл обработки команд Sound Manager, сериализация стилей для множественных прогонов, расширенные функции MIDI/синтеза
- ✅ **Система изменения размера окон**: Интерактивное изменение размера с корректной обработкой оформления, маркером изменения размера и очисткой рабочего стола
- ✅ **Трансляция клавиатуры PS/2**: Полное отображение скан-кодов набора 1 в коды клавиш Toolbox
- ✅ **Мультиплатформенный HAL**: Поддержка x86, ARM и PowerPC с чистой абстракцией

## 📊 Полнота реализации проекта

**Общая основная функциональность**: ~94% реализовано (оценка)

### Полностью работающие компоненты ✅

- **Уровень абстракции оборудования (HAL)**: Полная абстракция платформ для x86/ARM/PowerPC
- **Система загрузки**: Успешная загрузка через GRUB2/Multiboot2 на x86
- **Последовательное логирование**: Модульное логирование с фильтрацией во время выполнения (Error/Warn/Info/Debug/Trace)
- **Графическая основа**: Фреймбуфер VESA (800x600x32) с примитивами QuickDraw, включая режим XOR
- **Отрисовка рабочего стола**: Строка меню System 7 с радужным логотипом Apple, значки и узоры рабочего стола
- **Типографика**: Растровый шрифт Chicago с попиксельной отрисовкой и правильным кернингом, расширенный Mac Roman (0x80-0xFF) для европейских символов с диакритикой
- **Интернационализация (i18n)**: Локализация на основе ресурсов для 11 языков (английский, французский, немецкий, испанский, японский, китайский, корейский, русский, украинский, польский, чешский), Locale Manager с выбором языка при загрузке, инфраструктура многобайтовой кодировки CJK
- **Font Manager**: Поддержка множественных размеров (9-24pt), синтез стилей, разбор FOND/NFNT, LRU-кэширование
- **Система ввода**: Клавиатура и мышь PS/2 с полной пересылкой событий
- **Event Manager**: Кооперативная многозадачность через WaitNextEvent с единой очередью событий
- **Memory Manager**: Зонное распределение памяти с интеграцией интерпретатора 68K
- **Menu Manager**: Полноценные выпадающие меню с отслеживанием мыши и SaveBits/RestoreBits
- **Файловая система**: HFS с реализацией B-дерева, окна папок с перечислением VFS
- **Window Manager**: Перетаскивание, изменение размера (с маркером изменения размера), наложение слоёв, активация
- **Time Manager**: Точная калибровка TSC, микросекундная точность, проверка поколений
- **Resource Manager**: Бинарный поиск O(log n), LRU-кэш, комплексная валидация
- **Gestalt Manager**: Системная информация для нескольких архитектур с определением архитектуры
- **TextEdit Manager**: Полноценное редактирование текста с интеграцией буфера обмена
- **Scrap Manager**: Классический буфер обмена Mac OS с поддержкой множественных форматов
- **Приложение SimpleText**: Полнофункциональный MDI-редактор текста с вырезанием/копированием/вставкой
- **List Manager**: Элементы управления списками, совместимые с System 7.1, с навигацией с клавиатуры
- **Control Manager**: Стандартные элементы управления и полосы прокрутки с реализацией CDEF
- **Dialog Manager**: Навигация с клавиатуры, кольца фокуса, горячие клавиши
- **Segment Loader**: Портативная ISA-независимая система загрузки сегментов 68K с релокацией
- **Интерпретатор M68K**: Полная диспетчеризация инструкций с 84 обработчиками опкодов, всеми 14 режимами адресации, фреймворком исключений/ловушек
- **Sound Manager**: Обработка команд, конвертация MIDI, управление каналами, обратные вызовы
- **Device Manager**: Управление DCE, установка/удаление драйверов и операции ввода-вывода
- **Экран загрузки**: Полноценный интерфейс загрузки с отслеживанием прогресса, управлением фазами и заставкой
- **Color Manager**: Управление состоянием цвета с интеграцией QuickDraw

### Частично реализовано ⚠️

- **Интеграция приложений**: Интерпретатор M68K и загрузчик сегментов завершены; необходимо интеграционное тестирование для проверки выполнения реальных приложений
- **Процедуры определения окон (WDEF)**: Базовая структура создана, частичная диспетчеризация
- **Speech Manager**: Только каркас API и сквозная передача звука; движок синтеза речи не реализован
- **Обработка исключений (RTE)**: Возврат из исключения частично реализован (в настоящее время останавливается вместо восстановления контекста)

### Ещё не реализовано ❌

- **Печать**: Система печати отсутствует
- **Сеть**: Нет функциональности AppleTalk или сетевого взаимодействия
- **Настольные аксессуары**: Только каркас
- **Расширенное аудио**: Воспроизведение сэмплов, микширование (ограничение PC-спикера)

### Подсистемы, не включённые в компиляцию 🔧

Следующие компоненты имеют исходный код, но не интегрированы в ядро:
- **AppleEventManager** (8 файлов): Межприложенное взаимодействие; намеренно исключён из-за зависимостей от pthread, несовместимых с автономной средой
- **FontResources** (только заголовок): Определения типов ресурсов шрифтов; фактическая поддержка шрифтов обеспечивается скомпилированным FontResourceLoader.c

## 🏗️ Архитектура

### Технические характеристики

- **Архитектура**: Мультиархитектурная через HAL (x86, ARM, PowerPC)
- **Протокол загрузки**: Multiboot2 (x86), платформо-зависимые загрузчики
- **Графика**: Фреймбуфер VESA, 800x600 при 32-битном цвете
- **Карта памяти**: Ядро загружается по физическому адресу 1 МБ (x86)
- **Таймеры**: Архитектурно-независимые с микросекундной точностью (RDTSC/регистры таймеров)
- **Производительность**: Промах кэша ресурсов <15 мкс, попадание в кэш <2 мкс, дрейф таймера <100 ppm

### Статистика кодовой базы

- **225+ исходных файлов** с ~57 500+ строками кода
- **145+ заголовочных файлов** в 28+ подсистемах
- **69 типов ресурсов**, извлечённых из System 7.1
- **Время компиляции**: 3-5 секунд на современном оборудовании
- **Размер ядра**: ~4,16 МБ
- **Размер ISO**: ~12,5 МБ

## 🔨 Сборка

### Требования

- **GCC** с поддержкой 32-бит (`gcc-multilib` на 64-битных системах)
- **GNU Make**
- **Инструменты GRUB**: `grub-mkrescue` (из `grub2-common` или `grub-pc-bin`)
- **QEMU** для тестирования (`qemu-system-i386`)
- **Python 3** для обработки ресурсов
- **xxd** для двоичной конвертации
- *(Опционально)* Кросс-инструментарий **powerpc-linux-gnu** для сборки под PowerPC

### Установка на Ubuntu/Debian

```bash
sudo apt-get install build-essential gcc-multilib grub-pc-bin xorriso qemu-system-x86 python3 vim-common
```

### Команды сборки

```bash
# Сборка ядра (x86 по умолчанию)
make

# Сборка для конкретной платформы
make PLATFORM=x86
make PLATFORM=arm        # требуется ARM bare-metal GCC
make PLATFORM=ppc        # экспериментально; требуется PowerPC ELF toolchain

# Создание загрузочного ISO
make iso

# Сборка со всеми языками
make LOCALE_FR=1 LOCALE_DE=1 LOCALE_ES=1 LOCALE_JA=1 LOCALE_ZH=1 LOCALE_KO=1 LOCALE_RU=1 LOCALE_UK=1 LOCALE_PL=1 LOCALE_CS=1

# Сборка с одним дополнительным языком
make LOCALE_FR=1

# Сборка и запуск в QEMU
make run

# Очистка артефактов
make clean

# Отображение статистики сборки
make info
```

## 🚀 Запуск

### Быстрый старт (QEMU)

```bash
# Стандартный запуск с последовательным логированием
make run

# Ручной запуск с параметрами
qemu-system-i386 -cdrom system71.iso -serial file:/tmp/serial.log -display sdl -vga std -m 256M
```

### Параметры QEMU

```bash
# С выводом последовательной консоли
qemu-system-i386 -cdrom system71.iso -serial stdio -display sdl -m 256M

# Без графики (headless)
qemu-system-i386 -cdrom system71.iso -serial stdio -display none -m 256M

# С отладкой GDB
make debug
# В другом терминале: gdb kernel.elf -ex "target remote :1234"
```

### Философия проекта

**Археологический подход** с реализацией на основе фактических данных:
1. Основан на документации Inside Macintosh и MPW Universal Interfaces
2. Все ключевые решения снабжены идентификаторами находок со ссылками на подтверждающие данные
3. Цель: поведенческое соответствие оригинальной System 7, а не модернизация
4. Реализация «с чистого листа» (без использования оригинального исходного кода Apple)

## 🐛 Известные проблемы

1. **Артефакты перетаскивания значков**: Незначительные визуальные артефакты при перетаскивании значков рабочего стола
2. **Выполнение M68K не реализовано**: Загрузчик сегментов завершён, цикл выполнения не реализован
3. **Нет поддержки TrueType**: Только растровые шрифты (Chicago)
4. **HFS только для чтения**: Виртуальная файловая система, без обратной записи на диск
5. **Нет гарантий стабильности**: Сбои и непредвиденное поведение — обычное явление
