> ⚠️ **КОНЦЕПТ-ПІДТВЕРДЖЕННЯ** - Це експериментальна, навчальна реімплементація Apple Macintosh System 7. Це НЕ готовий продукт і не повинно розглядатися як програмне забезпечення виробничого рівня.

Реімплементація з відкритим кодом Apple Macintosh System 7 для сучасного обладнання x86, з можливістю завантаження через GRUB2/Multiboot2. Цей проєкт має на меті відтворити класичний досвід Mac OS, одночасно документуючи архітектуру System 7 через аналіз зворотної інженерії.

## 🎯 Статус проєкту

**Поточний стан**: Активна розробка, ~94% основної функціональності завершено

### Останні оновлення (листопад 2025)

#### Покращення Sound Manager ✅ ЗАВЕРШЕНО
- **Оптимізована конвертація MIDI**: Спільний хелпер `SndMidiNoteToFreq()` з таблицею пошуку на 37 записів (C3-B5) та резервним варіантом на основі октав для повного діапазону MIDI (0-127)
- **Підтримка асинхронного відтворення**: Повна інфраструктура зворотних викликів для відтворення файлів (`FilePlayCompletionUPP`) та виконання команд (`SndCallBackProcPtr`)
- **Маршрутизація аудіо на основі каналів**: Багаторівнева система пріоритетів з контролем вимкнення та увімкнення
  - 4-рівневі канали пріоритету (0-3) для маршрутизації апаратного виведення
  - Незалежне керування вимкненням та увімкненням для кожного каналу
  - `SndGetActiveChannel()` повертає активний канал з найвищим пріоритетом
  - Коректна ініціалізація каналу з прапорцем увімкнення за замовчуванням
- **Реалізація виробничого рівня**: Весь код компілюється чисто, порушень malloc/free не виявлено
- **Коміти**: 07542c5 (оптимізація MIDI), 1854fe6 (асинхронні зворотні виклики), a3433c6 (маршрутизація каналів)

#### Попередні досягнення
- ✅ **Фаза розширених функцій**: Цикл обробки команд Sound Manager, серіалізація стилів для декількох прогонів, розширені функції MIDI/синтезу
- ✅ **Система зміни розміру вікон**: Інтерактивна зміна розміру з належною обробкою обрамлення, полем збільшення та очищенням робочого столу
- ✅ **Трансляція клавіатури PS/2**: Повне відображення сканкодів набору 1 у коди клавіш Toolbox
- ✅ **Мультиплатформний HAL**: Підтримка x86, ARM та PowerPC з чистою абстракцією

## 📊 Повнота проєкту

**Загальна основна функціональність**: ~94% завершено (оцінка)

### Повністю працює ✅

- **Рівень абстракції обладнання (HAL)**: Повна платформна абстракція для x86/ARM/PowerPC
- **Система завантаження**: Успішне завантаження через GRUB2/Multiboot2 на x86
- **Серійне логування**: Модульне логування з фільтрацією під час виконання (Error/Warn/Info/Debug/Trace)
- **Графічна основа**: Фреймбуфер VESA (800x600x32) з примітивами QuickDraw, включаючи режим XOR
- **Рендеринг робочого столу**: Панель меню System 7 з райдужним логотипом Apple, піктограмами та шаблонами робочого столу
- **Типографіка**: Растровий шрифт Chicago з піксельно-точним рендерингом та належним кернінгом, розширений Mac Roman (0x80-0xFF) для європейських символів з діакритиками
- **Інтернаціоналізація (i18n)**: Локалізація на основі ресурсів з 11 мовами (англійська, французька, німецька, іспанська, японська, китайська, корейська, російська, українська, польська, чеська), Locale Manager з вибором мови при завантаженні, інфраструктура багатобайтового кодування CJK
- **Font Manager**: Підтримка кількох розмірів (9-24pt), синтез стилів, парсинг FOND/NFNT, кешування LRU
- **Система введення**: Клавіатура та миша PS/2 з повною пересилкою подій
- **Event Manager**: Кооперативна багатозадачність через WaitNextEvent з уніфікованою чергою подій
- **Memory Manager**: Зонове виділення пам'яті з інтеграцією інтерпретатора 68K
- **Menu Manager**: Повні випадні меню з відстеженням миші та SaveBits/RestoreBits
- **Файлова система**: HFS з реалізацією B-дерева, вікна тек з перерахуванням VFS
- **Window Manager**: Перетягування, зміна розміру (з полем збільшення), шарування, активація
- **Time Manager**: Точна калібрація TSC, мікросекундна точність, перевірка поколінь
- **Resource Manager**: Бінарний пошук O(log n), кеш LRU, комплексна валідація
- **Gestalt Manager**: Мультиархітектурна системна інформація з визначенням архітектури
- **TextEdit Manager**: Повне редагування тексту з інтеграцією буфера обміну
- **Scrap Manager**: Класичний буфер обміну Mac OS з підтримкою кількох форматів
- **Додаток SimpleText**: Повнофункціональний MDI текстовий редактор з вирізанням/копіюванням/вставкою
- **List Manager**: Елементи керування списками, сумісні з System 7.1, з клавіатурною навігацією
- **Control Manager**: Стандартні елементи керування та смуги прокрутки з реалізацією CDEF
- **Dialog Manager**: Клавіатурна навігація, кільця фокусу, клавіатурні скорочення
- **Segment Loader**: Портативна ISA-незалежна система завантаження сегментів 68K з релокацією
- **Інтерпретатор M68K**: Повна диспетчеризація інструкцій з 84 обробниками опкодів, усі 14 режимів адресації, фреймворк виключень/пасток
- **Sound Manager**: Обробка команд, конвертація MIDI, керування каналами, зворотні виклики
- **Device Manager**: Керування DCE, встановлення/видалення драйверів та операції вводу/виводу
- **Екран запуску**: Повний інтерфейс завантаження з відстеженням прогресу, керуванням фазами та заставкою
- **Color Manager**: Керування станом кольору з інтеграцією QuickDraw

### Частково реалізовано ⚠️

- **Інтеграція додатків**: Інтерпретатор M68K та завантажувач сегментів завершені; потрібне інтеграційне тестування для перевірки виконання реальних додатків
- **Процедури визначення вікон (WDEF)**: Основна структура на місці, часткова диспетчеризація
- **Speech Manager**: Лише фреймворк API та наскрізне аудіо; двигун синтезу мовлення не реалізовано
- **Обробка виключень (RTE)**: Повернення з виключення частково реалізовано (наразі зупиняється замість відновлення контексту)

### Ще не реалізовано ❌

- **Друк**: Система друку відсутня
- **Мережа**: Функціональність AppleTalk або мережі відсутня
- **Аксесуари робочого столу**: Лише фреймворк
- **Розширене аудіо**: Відтворення семплів, мікшування (обмеження PC speaker)

### Підсистеми, що не компілюються 🔧

Наступні мають вихідний код, але не інтегровані в ядро:
- **AppleEventManager** (8 файлів): Міжпрограмний обмін повідомленнями; навмисно виключений через залежності від pthread, несумісні з автономним середовищем
- **FontResources** (лише заголовок): Визначення типів ресурсів шрифтів; фактична підтримка шрифтів забезпечується скомпільованим FontResourceLoader.c

## 🏗️ Архітектура

### Технічні характеристики

- **Архітектура**: Мультиархітектурність через HAL (x86, ARM, PowerPC готові)
- **Протокол завантаження**: Multiboot2 (x86), платформоспецифічні завантажувачі
- **Графіка**: Фреймбуфер VESA, 800x600 @ 32-бітний колір
- **Компонування пам'яті**: Ядро завантажується за фізичною адресою 1 МБ (x86)
- **Хронометраж**: Архітектурно-незалежний з мікросекундною точністю (RDTSC/регістри таймера)
- **Продуктивність**: Промах кешу ресурсів <15 мкс, влучення кешу <2 мкс, дрейф таймера <100 ppm

### Статистика кодової бази

- **225+ вихідних файлів** з ~57 500+ рядками коду
- **145+ заголовкових файлів** у 28+ підсистемах
- **69 типів ресурсів**, витягнутих з System 7.1
- **Час компіляції**: 3-5 секунд на сучасному обладнанні
- **Розмір ядра**: ~4,16 МБ
- **Розмір ISO**: ~12,5 МБ

## 🔨 Збирання

### Вимоги

- **GCC** з підтримкою 32-біт (`gcc-multilib` на 64-бітних системах)
- **GNU Make**
- **Інструменти GRUB**: `grub-mkrescue` (з `grub2-common` або `grub-pc-bin`)
- **QEMU** для тестування (`qemu-system-i386`)
- **Python 3** для обробки ресурсів
- **xxd** для двійкової конвертації
- *(Опціонально)* **powerpc-linux-gnu** крос-інструментарій для збірок PowerPC

### Встановлення на Ubuntu/Debian

```bash
sudo apt-get install build-essential gcc-multilib grub-pc-bin xorriso qemu-system-x86 python3 vim-common
```

### Команди збирання

```bash
# Збирання ядра (x86 за замовчуванням)
make

# Збирання для конкретної платформи
make PLATFORM=x86
make PLATFORM=arm        # потребує ARM bare-metal GCC
make PLATFORM=ppc        # експериментально; потребує PowerPC ELF інструментарій

# Створення завантажувального ISO
make iso

# Збирання з усіма мовами
make LOCALE_FR=1 LOCALE_DE=1 LOCALE_ES=1 LOCALE_JA=1 LOCALE_ZH=1 LOCALE_KO=1 LOCALE_RU=1 LOCALE_UK=1 LOCALE_PL=1 LOCALE_CS=1

# Збирання з однією додатковою мовою
make LOCALE_FR=1

# Збирання та запуск у QEMU
make run

# Очищення артефактів
make clean

# Показ статистики збирання
make info
```

## 🚀 Запуск

### Швидкий старт (QEMU)

```bash
# Стандартний запуск з серійним логуванням
make run

# Вручну з параметрами
qemu-system-i386 -cdrom system71.iso -serial file:/tmp/serial.log -display sdl -vga std -m 256M
```

### Параметри QEMU

```bash
# З виведенням серійного порту в консоль
qemu-system-i386 -cdrom system71.iso -serial stdio -display sdl -m 256M

# Безголовий режим (без графічного дисплея)
qemu-system-i386 -cdrom system71.iso -serial stdio -display none -m 256M

# З налагодженням GDB
make debug
# В іншому терміналі: gdb kernel.elf -ex "target remote :1234"
```

## 🐛 Відомі проблеми

1. **Артефакти перетягування піктограм**: Незначні візуальні артефакти під час перетягування піктограм на робочому столі
2. **Виконання M68K заглушене**: Завантажувач сегментів завершений, цикл виконання не реалізований
3. **Немає підтримки TrueType**: Лише растрові шрифти (Chicago)
4. **HFS лише для читання**: Віртуальна файлова система, без зворотного запису на диск
5. **Без гарантій стабільності**: Збої та непередбачувана поведінка є звичайним явищем
