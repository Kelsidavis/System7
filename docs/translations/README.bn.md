> ⚠️ **ধারণার প্রমাণ** - এটি Apple-এর Macintosh System 7-এর একটি পরীক্ষামূলক, শিক্ষামূলক পুনর্নির্মাণ। এটি কোনো সম্পূর্ণ পণ্য নয় এবং প্রোডাকশন-রেডি সফটওয়্যার হিসেবে বিবেচনা করা উচিত নয়।

আধুনিক x86 হার্ডওয়্যারের জন্য Apple Macintosh System 7-এর একটি ওপেন-সোর্স পুনর্নির্মাণ, GRUB2/Multiboot2 এর মাধ্যমে বুটযোগ্য। এই প্রকল্পের লক্ষ্য হলো রিভার্স ইঞ্জিনিয়ারিং বিশ্লেষণের মাধ্যমে System 7 আর্কিটেক্চার নথিভুক্ত করার পাশাপাশি ক্লাসিক Mac OS অভিজ্ঞতা পুনরায় তৈরি করা।

## 🎯 প্রকল্পের অবস্থা

**বর্তমান অবস্থা**: সক্রিয় উন্নয়ন চলমান, ~৯৪% মূল কার্যকারিতা সম্পন্ন

### সর্বশেষ আপডেট (নভেম্বর ২০২৫)

#### Sound Manager উন্নতি ✅ সম্পন্ন
- **অপ্টিমাইজড MIDI রূপান্তর**: ৩৭-এন্ট্রি লুকআপ টেবিল (C3-B5) এবং সম্পূর্ণ MIDI পরিসরের (0-127) জন্য অক্টেভ-ভিত্তিক ফলব্যাক সহ শেয়ার্ড `SndMidiNoteToFreq()` হেল্পার
- **অ্যাসিঙ্ক প্লেব্যাক সাপোর্ট**: ফাইল প্লেব্যাক (`FilePlayCompletionUPP`) এবং কমান্ড এক্সিকিউশন (`SndCallBackProcPtr`) উভয়ের জন্য সম্পূর্ণ কলব্যাক অবকাঠামো
- **চ্যানেল-ভিত্তিক অডিও রাউটিং**: মিউট এবং এনেবল নিয়ন্ত্রণ সহ বহু-স্তরের অগ্রাধিকার ব্যবস্থা
  - হার্ডওয়্যার আউটপুট রাউটিং-এর জন্য ৪-স্তরের অগ্রাধিকার চ্যানেল (0-3)
  - প্রতিটি চ্যানেলের জন্য স্বতন্ত্র মিউট এবং এনেবল নিয়ন্ত্রণ
  - `SndGetActiveChannel()` সর্বোচ্চ-অগ্রাধিকার সক্রিয় চ্যানেল ফেরত দেয়
  - ডিফল্টভাবে এনেবলড ফ্ল্যাগ সহ সঠিক চ্যানেল ইনিশিয়ালাইজেশন
- **প্রোডাকশন-মানের বাস্তবায়ন**: সমস্ত কোড পরিষ্কারভাবে কম্পাইল হয়, কোনো malloc/free লঙ্ঘন সনাক্ত হয়নি
- **কমিট**: 07542c5 (MIDI অপ্টিমাইজেশন), 1854fe6 (অ্যাসিঙ্ক কলব্যাক), a3433c6 (চ্যানেল রাউটিং)

#### পূর্ববর্তী সেশনের অর্জনসমূহ
- ✅ **অ্যাডভান্সড ফিচার পর্ব**: Sound Manager কমান্ড প্রসেসিং লুপ, মাল্টি-রান স্টাইল সিরিয়ালাইজেশন, এক্সটেন্ডেড MIDI/সিন্থেসিস ফিচার
- ✅ **উইন্ডো রিসাইজ সিস্টেম**: সঠিক ক্রোম হ্যান্ডলিং, গ্রো বক্স এবং ডেস্কটপ ক্লিনআপ সহ ইন্টারেক্টিভ রিসাইজিং
- ✅ **PS/2 কীবোর্ড ট্রান্সলেশন**: সম্পূর্ণ সেট 1 স্ক্যানকোড থেকে Toolbox কী কোড ম্যাপিং
- ✅ **মাল্টি-প্ল্যাটফর্ম HAL**: পরিচ্ছন্ন অ্যাবস্ট্রাকশন সহ x86, ARM এবং PowerPC সাপোর্ট

## 📊 প্রকল্পের সম্পূর্ণতা

**সামগ্রিক মূল কার্যকারিতা**: ~৯৪% সম্পন্ন (আনুমানিক)

### যা সম্পূর্ণ কাজ করে ✅

- **Hardware Abstraction Layer (HAL)**: x86/ARM/PowerPC-এর জন্য সম্পূর্ণ প্ল্যাটফর্ম অ্যাবস্ট্রাকশন
- **বুট সিস্টেম**: x86-এ GRUB2/Multiboot2 এর মাধ্যমে সফলভাবে বুট হয়
- **সিরিয়াল লগিং**: রানটাইম ফিল্টারিং (Error/Warn/Info/Debug/Trace) সহ মডিউল-ভিত্তিক লগিং
- **গ্রাফিক্স ফাউন্ডেশন**: XOR মোড সহ QuickDraw প্রিমিটিভ সমেত VESA ফ্রেমবাফার (800x600x32)
- **ডেস্কটপ রেন্ডারিং**: রেইনবো Apple লোগো, আইকন এবং ডেস্কটপ প্যাটার্ন সহ System 7 মেনু বার
- **টাইপোগ্রাফি**: পিক্সেল-পারফেক্ট রেন্ডারিং এবং যথাযথ কার্নিং সহ Chicago বিটম্যাপ ফন্ট, ইউরোপীয় অ্যাক্সেন্টেড অক্ষরের জন্য এক্সটেন্ডেড Mac Roman (0x80-0xFF)
- **আন্তর্জাতিকীকরণ (i18n)**: ৩৮টি ভাষা সহ রিসোর্স-ভিত্তিক লোকালাইজেশন (ইংরেজি, ফরাসি, জার্মান, স্প্যানিশ, ইতালীয়, পর্তুগিজ, ডাচ, ডেনিশ, নরওয়েজীয়, সুইডিশ, ফিনিশ, আইসল্যান্ডীয়, গ্রিক, তুর্কি, পোলিশ, চেক, স্লোভাক, স্লোভেনীয়, ক্রোয়েশীয়, হাঙ্গেরীয়, রোমানীয়, বুলগেরীয়, আলবেনীয়, এস্তোনীয়, লাটভীয়, লিথুয়ানীয়, ম্যাসিডোনীয়, মন্টেনেগ্রীয়, রুশ, ইউক্রেনীয়, আরবি, জাপানি, সরলীকৃত চীনা, ঐতিহ্যবাহী চীনা, কোরীয়, হিন্দি, বাংলা, উর্দু), বুট-টাইম ভাষা নির্বাচন সহ Locale Manager, CJK মাল্টি-বাইট এনকোডিং অবকাঠামো
- **Font Manager**: মাল্টি-সাইজ সাপোর্ট (9-24pt), স্টাইল সিন্থেসিস, FOND/NFNT পার্সিং, LRU ক্যাশিং
- **ইনপুট সিস্টেম**: সম্পূর্ণ ইভেন্ট ফরওয়ার্ডিং সহ PS/2 কীবোর্ড এবং মাউস
- **Event Manager**: ইউনিফাইড ইভেন্ট কিউ সহ WaitNextEvent এর মাধ্যমে সমবায়মূলক মাল্টিটাস্কিং
- **Memory Manager**: 68K ইন্টারপ্রেটার ইন্টিগ্রেশন সহ জোন-ভিত্তিক অ্যালোকেশন
- **Menu Manager**: মাউস ট্র্যাকিং এবং SaveBits/RestoreBits সহ সম্পূর্ণ ড্রপডাউন মেনু
- **ফাইল সিস্টেম**: B-tree বাস্তবায়ন সহ HFS, VFS এনুমারেশন সহ ফোল্ডার উইন্ডো
- **Window Manager**: ড্র্যাগিং, রিসাইজিং (গ্রো বক্স সহ), লেয়ারিং, অ্যাক্টিভেশন
- **Time Manager**: নির্ভুল TSC ক্যালিব্রেশন, মাইক্রোসেকেন্ড নির্ভুলতা, জেনারেশন চেকিং
- **Resource Manager**: O(log n) বাইনারি সার্চ, LRU ক্যাশ, ব্যাপক ভ্যালিডেশন
- **Gestalt Manager**: আর্কিটেক্চার সনাক্তকরণ সহ মাল্টি-আর্কিটেক্চার সিস্টেম তথ্য
- **TextEdit Manager**: ক্লিপবোর্ড ইন্টিগ্রেশন সহ সম্পূর্ণ টেক্সট এডিটিং
- **Scrap Manager**: একাধিক ফ্লেভার সাপোর্ট সহ ক্লাসিক Mac OS ক্লিপবোর্ড
- **SimpleText অ্যাপ্লিকেশন**: কাট/কপি/পেস্ট সহ সম্পূর্ণ-বৈশিষ্ট্যযুক্ত MDI টেক্সট এডিটর
- **List Manager**: কীবোর্ড নেভিগেশন সহ System 7.1-সামঞ্জস্যপূর্ণ লিস্ট কন্ট্রোল
- **Control Manager**: CDEF বাস্তবায়ন সহ স্ট্যান্ডার্ড এবং স্ক্রলবার কন্ট্রোল
- **Dialog Manager**: কীবোর্ড নেভিগেশন, ফোকাস রিং, কীবোর্ড শর্টকাট
- **Segment Loader**: রিলোকেশন সহ পোর্টেবল ISA-অজ্ঞেয়বাদী 68K সেগমেন্ট লোডিং সিস্টেম
- **M68K Interpreter**: ৮৪টি অপকোড হ্যান্ডলার, সমস্ত ১৪টি অ্যাড্রেসিং মোড, এক্সেপশন/ট্র্যাপ ফ্রেমওয়ার্ক সহ সম্পূর্ণ ইন্সট্রাকশন ডিসপ্যাচ
- **Sound Manager**: কমান্ড প্রসেসিং, MIDI রূপান্তর, চ্যানেল ব্যবস্থাপনা, কলব্যাক
- **Device Manager**: DCE ব্যবস্থাপনা, ড্রাইভার ইনস্টলেশন/অপসারণ এবং I/O অপারেশন
- **Startup Screen**: প্রগ্রেস ট্র্যাকিং, ফেজ ম্যানেজমেন্ট এবং স্প্ল্যাশ স্ক্রিন সহ সম্পূর্ণ বুট UI
- **Color Manager**: QuickDraw ইন্টিগ্রেশন সহ রঙ অবস্থা ব্যবস্থাপনা

### আংশিকভাবে বাস্তবায়িত ⚠️

- **অ্যাপ্লিকেশন ইন্টিগ্রেশন**: M68K ইন্টারপ্রেটার এবং সেগমেন্ট লোডার সম্পন্ন; প্রকৃত অ্যাপ্লিকেশন চলে কিনা যাচাই করতে ইন্টিগ্রেশন টেস্টিং প্রয়োজন
- **Window Definition Procedures (WDEF)**: মূল কাঠামো স্থাপিত, আংশিক ডিসপ্যাচ
- **Speech Manager**: API ফ্রেমওয়ার্ক এবং অডিও পাসথ্রু শুধুমাত্র; স্পিচ সিন্থেসিস ইঞ্জিন বাস্তবায়িত হয়নি
- **Exception Handling (RTE)**: এক্সেপশন থেকে প্রত্যাবর্তন আংশিকভাবে বাস্তবায়িত (বর্তমানে কনটেক্সট পুনরুদ্ধারের পরিবর্তে থেমে যায়)

### এখনও বাস্তবায়িত হয়নি ❌

- **প্রিন্টিং**: কোনো প্রিন্ট সিস্টেম নেই
- **নেটওয়ার্কিং**: কোনো AppleTalk বা নেটওয়ার্ক কার্যকারিতা নেই
- **Desk Accessories**: শুধুমাত্র ফ্রেমওয়ার্ক
- **উন্নত অডিও**: স্যাম্পল প্লেব্যাক, মিক্সিং (PC স্পিকার সীমাবদ্ধতা)

### কম্পাইল হয়নি এমন সাবসিস্টেম 🔧

নিম্নলিখিতগুলির সোর্স কোড আছে কিন্তু কার্নেলে ইন্টিগ্রেট করা হয়নি:
- **AppleEventManager** (৮টি ফাইল): আন্তঃ-অ্যাপ্লিকেশন মেসেজিং; ফ্রিস্ট্যান্ডিং এনভায়রনমেন্টের সাথে অসামঞ্জস্যপূর্ণ pthread নির্ভরতার কারণে ইচ্ছাকৃতভাবে বাদ দেওয়া হয়েছে
- **FontResources** (শুধুমাত্র হেডার): ফন্ট রিসোর্স টাইপ সংজ্ঞা; প্রকৃত ফন্ট সাপোর্ট কম্পাইলকৃত FontResourceLoader.c দ্বারা প্রদান করা হয়

## 🏗️ আর্কিটেক্চার

### প্রযুক্তিগত বিশেষ বিবরণ

- **আর্কিটেক্চার**: HAL এর মাধ্যমে মাল্টি-আর্কিটেক্চার (x86, ARM, PowerPC প্রস্তুত)
- **বুট প্রোটোকল**: Multiboot2 (x86), প্ল্যাটফর্ম-নির্দিষ্ট বুটলোডার
- **গ্রাফিক্স**: VESA ফ্রেমবাফার, 800x600 @ 32-বিট রঙ
- **মেমরি লেআউট**: কার্নেল 1MB ফিজিক্যাল অ্যাড্রেসে লোড হয় (x86)
- **টাইমিং**: মাইক্রোসেকেন্ড নির্ভুলতা সহ আর্কিটেক্চার-অজ্ঞেয়বাদী (RDTSC/টাইমার রেজিস্টার)
- **কর্মক্ষমতা**: কোল্ড রিসোর্স মিস <15µs, ক্যাশ হিট <2µs, টাইমার ড্রিফট <100ppm

### কোডবেস পরিসংখ্যান

- **২২৫+ সোর্স ফাইল** ~৫৭,৫০০+ লাইন কোড সহ
- **১৪৫+ হেডার ফাইল** ২৮+ সাবসিস্টেম জুড়ে
- **৬৯টি রিসোর্স টাইপ** System 7.1 থেকে নিষ্কাশিত
- **কম্পাইলেশন সময়**: আধুনিক হার্ডওয়্যারে ৩-৫ সেকেন্ড
- **কার্নেল আকার**: ~4.16 MB
- **ISO আকার**: ~12.5 MB

## 🔨 বিল্ড করা

### প্রয়োজনীয়তা

- 32-বিট সাপোর্ট সহ **GCC** (64-বিটে `gcc-multilib`)
- **GNU Make**
- **GRUB টুলস**: `grub-mkrescue` (`grub2-common` বা `grub-pc-bin` থেকে)
- পরীক্ষার জন্য **QEMU** (`qemu-system-i386`)
- রিসোর্স প্রসেসিং-এর জন্য **Python 3**
- বাইনারি রূপান্তরের জন্য **xxd**
- *(ঐচ্ছিক)* PowerPC বিল্ডের জন্য **powerpc-linux-gnu** ক্রস টুলচেইন

### Ubuntu/Debian ইনস্টলেশন

```bash
sudo apt-get install build-essential gcc-multilib grub-pc-bin xorriso qemu-system-x86 python3 vim-common
```

### বিল্ড কমান্ড

```bash
# কার্নেল বিল্ড করুন (ডিফল্টরূপে x86)
make

# নির্দিষ্ট প্ল্যাটফর্মের জন্য বিল্ড
make PLATFORM=x86
make PLATFORM=arm        # ARM বেয়ার-মেটাল GCC প্রয়োজন
make PLATFORM=ppc        # পরীক্ষামূলক; PowerPC ELF টুলচেইন প্রয়োজন

# বুটযোগ্য ISO তৈরি করুন
make iso

# সমস্ত ভাষা সহ বিল্ড করুন
make LOCALE_FR=1 LOCALE_DE=1 LOCALE_ES=1 LOCALE_JA=1 LOCALE_ZH=1 LOCALE_KO=1 LOCALE_RU=1 LOCALE_UK=1 LOCALE_PL=1 LOCALE_CS=1 LOCALE_SQ=1 LOCALE_BG=1 LOCALE_HR=1 LOCALE_DA=1 LOCALE_NL=1 LOCALE_ET=1 LOCALE_FI=1 LOCALE_EL=1 LOCALE_HU=1 LOCALE_IS=1 LOCALE_IT=1 LOCALE_LV=1 LOCALE_LT=1 LOCALE_MK=1 LOCALE_ME=1 LOCALE_NO=1 LOCALE_PT=1 LOCALE_RO=1 LOCALE_SK=1 LOCALE_SL=1 LOCALE_SV=1 LOCALE_TR=1 LOCALE_HI=1 LOCALE_TW=1 LOCALE_AR=1 LOCALE_BN=1 LOCALE_UR=1

# একটি অতিরিক্ত ভাষা সহ বিল্ড করুন
make LOCALE_FR=1

# বিল্ড করুন এবং QEMU-তে চালান
make run

# আর্টিফ্যাক্ট পরিষ্কার করুন
make clean

# বিল্ড পরিসংখ্যান প্রদর্শন করুন
make info
```

## 🚀 চালানো

### দ্রুত শুরু (QEMU)

```bash
# সিরিয়াল লগিং সহ স্ট্যান্ডার্ড রান
make run

# বিকল্পসমূহ সহ ম্যানুয়ালি
qemu-system-i386 -cdrom system71.iso -serial file:/tmp/serial.log -display sdl -vga std -m 256M
```

### QEMU বিকল্পসমূহ

```bash
# কনসোল সিরিয়াল আউটপুট সহ
qemu-system-i386 -cdrom system71.iso -serial stdio -display sdl -m 256M

# হেডলেস (গ্রাফিক্স ডিসপ্লে ছাড়া)
qemu-system-i386 -cdrom system71.iso -serial stdio -display none -m 256M

# GDB ডিবাগিং সহ
make debug
# অন্য টার্মিনালে: gdb kernel.elf -ex "target remote :1234"
```
